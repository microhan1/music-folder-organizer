## 음악 폴더 정리 v0.1.0 — 첫 릴리스

> **인터넷 연결 없이 동작합니다.**
> **기본값은 복사가 아니라 이동입니다. 되돌리기가 있습니다.**

뒤섞인 음악 파일을 태그(가수·앨범·트랙·제목) 기준으로 `가수/앨범/01 - 제목.mp3` 구조로 옮기고, 같은 곡이 여러 개 있으면 찾아 정리합니다. 태그가 비어 있으면 [음악 정보 채우기](https://github.com/microhan1/music-tag-filler)로 먼저 채우세요.

### 기능

- **미리보기 먼저**: 현재 경로 → 새 경로, 상태(정상·변경 없음·태그 부족·중복·충돌)를 보고 체크로 제외. 실행 전에는 아무것도 옮기지 않습니다.
- **정리 규칙**: 프리셋 3개 + 직접 입력. `{album_artist|artist}`처럼 "앞이 비면 뒤"를 쓸 수 있고, 트랙 태그가 없으면 파일명 앞 숫자를 씁니다.
- **중복 찾기 3단계**: 완전 동일(SHA-1) → 같은 곡(가수+제목, 길이 2초 이내) → 소리(Chromaprint 로컬 비교). 남길 파일을 추천(무손실 → 비트레이트)하고, 나머지는 지우지 않고 `_중복` 폴더로 옮깁니다.
- **가수 통합**: `岡田 有希子` / `岡田有希子` / `Minako Yoshida (吉田美奈子)` 같은 표기 차이를 한 폴더로. `artists.json`으로 직접 지정하고, 같은 앨범의 다른 표기는 물어본 뒤 적용합니다. 음악 정보 채우기 v0.1.6이 적는 MusicBrainz 아티스트 ID도 읽습니다.
- **되돌리기**: 실행마다 `organize_log.json`에 기록해 원래 경로·폴더 구조로 복구. 로그를 먼저 저장하지 못하면 아무것도 옮기지 않습니다. 다른 드라이브로 옮길 때는 SHA-1로 사본을 확인한 뒤 원본을 지웁니다.
- `.lrc`, 음악 정보 채우기 백업(`.tagbak.json`), `cover.jpg`·`folder.jpg`가 함께 옮겨지고, 비게 된 폴더는 지웁니다.
- 한국어 · English · 中文 · 日本語, 명령줄(`--dry-run`, `--undo` 등)도 지원합니다.

### 알아 두실 점

- GUI에서 "같은 곡"·"소리" 중복 그룹은 **적용**에 체크해야 반영됩니다. 베스트 앨범 곡이 원래 앨범 곡과 묶이기 때문입니다. 명령줄 `--dedupe`는 전부 적용하니 먼저 `--dry-run`으로 확인하세요.
- `.cue`·`.log`·`Artwork` 폴더는 옮기지 않으므로 그런 파일이 있는 원래 폴더는 남습니다.
- 휴지통으로 보낸 중복은 이 프로그램의 되돌리기로 돌아오지 않습니다(휴지통에서 복원).

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.1.0** — first release. Moves music into `Artist/Album/01 - Title` folders from tags, with a preview before anything moves and a full undo log. Finds duplicates in three stages (identical files, same song, same sound via local Chromaprint fingerprints) and moves the extras to a `_Duplicates` folder instead of deleting them. Merges artist spellings (IDs, normalization, `artists.json`, confirmed guesses). Offline, single exe, Korean · English · Chinese · Japanese.
