## 음악 폴더 정리 v0.3.0

쓰기 편하게 다듬은 버전입니다.

### 바뀐 것

- **되돌리기 기록.** 아래쪽 **되돌리기…**가 실행 기록 창을 엽니다. 실행마다 시간·방식·파일 수·대상 폴더·상태를 보여 주고, 고른 실행의 상세(이동·복사·휴지통·지운 빈 폴더 수, 그때 건너뛴 파일)도 보여 줍니다.
  - 가장 최근 것뿐 아니라 **아무 실행이나 골라** 되돌릴 수 있습니다.
  - 더 최근 실행이 같은 파일을 다시 옮겼으면 막고, 그 실행부터 되돌리라고 알려 줍니다(복사는 원본을 그대로 두므로 막지 않음).
  - 명령줄: `--history`(실행 ID 포함), `--undo-run ID`.
- **정리 규칙 도우미.** 입력칸 아래 치환자 버튼을 누르면 커서 위치에 들어가고, 그 아래에 표에서 고른 파일이 어떻게 바뀌는지 바로 보여 줍니다(폴더를 열기 전에는 예시 곡).
  - `{disc}`는 디스크가 2장 이상인 앨범에서만 들어가고, 1장짜리 앨범에서는 옆의 구분자와 함께 빠집니다. 프리셋 `{album_artist|artist}/{album}/{disc}-{track:02} - {title}` 추가(기본 규칙은 그대로).
- **설정 화면.** 오른쪽 위 **설정**에서 대체 문구(알 수 없는 가수 등), 중복 폴더 이름, artists.json·fpcalc·음악 정보 채우기 위치, 대표 이름 규칙을 바꿉니다. 저장 전에 이름에 못 쓰는 문자나 없는 파일을 검사합니다.
  - 중복 폴더 이름을 바꿔도 예전 이름의 폴더는 계속 스캔에서 빠집니다.

### 고친 것

- 미리보기를 다시 그릴 때 표에서 고른 줄이 풀리던 문제.
- 좁은 창에서 머리글 버튼이 눌려 보이던 문제.

저장 형식은 그대로라 이전 버전으로 정리한 것도 되돌릴 수 있고, 이전 실행도 기록 창에 나옵니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.3.0** — **Undo…** now opens a history of runs (time, mode, file count, destination, state, and files skipped back then); any run can be undone, unless a newer run moved the same files again, in which case it says which one to undo first (`--history`, `--undo-run ID` on the command line). The folder pattern gets placeholder buttons and a live example of the selected file, and `{disc}` only appears on multi-disc albums (new preset; the default pattern is unchanged). A **Settings** window covers fallback names, the duplicates folder name (old names stay excluded from scans), the artists.json, fpcalc and Music Tag Filler locations, and the artist-name rule. File formats are unchanged.
