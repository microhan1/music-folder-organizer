## 음악 폴더 정리 v0.4.1

"정리한 뒤 같은 폴더를 다시 실행해도 아무것도 움직이지 않아야 한다"를 무작위로 만든 어지러운 음악 폴더 2,400개로 점검해서 찾은 결함을 고친 버전입니다. 화면과 기능은 v0.4.0과 같습니다. 평소처럼 폴더 하나를 정리하고 끝내는 사용에서는 달라지는 것이 거의 없고, 아래는 **다시 실행하거나, 옵션·언어를 바꾸거나, 복사 모드를 반복할 때** 생기던 문제입니다.

### 고친 것

- **프로그램이 멈추던 문제.** 제목이 아주 긴 곡이 같은 앨범에 둘 이상 있고 경로가 길면, 미리보기를 계산하는 중에 끝나지 않고 멈췄습니다. 경로 길이 제한에 맞춰 이름을 자르면서 중복을 구분하는 번호 ` (2)`까지 같이 잘려 나갔기 때문입니다. 이제 번호 자리를 남기고 이름을 자릅니다.
- **제목 태그가 없는 파일의 이름이 실행할 때마다 길어지던 문제.** "태그 없는 파일도 정리"를 켜면 `01 track01` → `01 01 track01` → … 이었습니다. 이제 제목이 없는 파일은 **파일 이름을 그대로 두고 폴더만** 정리 규칙대로 옮깁니다(예전에는 `01 - 이름`처럼 번호를 붙였습니다).
- **cue 앨범의 이름이 두 번째 실행에서 바뀌던 문제.** cue가 따라가지 못하는 경우(곡이 여러 앨범으로 흩어짐, "앨범 부속 파일도 함께"를 끔, 이름이 경로 제한 때문에 잘림)에는 처음 실행에서 정리 규칙의 이름으로 한 번에 바꿉니다.
- **언어를 바꾸고 다시 실행하면 폴더가 통째로 옮겨지던 문제.** 비어 있는 가수·앨범·연도·장르에 쓰는 대체 이름("Unknown Album" ↔ "不明なアルバム")이 언어마다 달라, 언어를 바꾸면 라이브러리 전체가 이동 대상이었습니다. 이미 있는 대체 이름 폴더(파일 이름 앞의 가수 자리 포함)는 어느 언어든 그대로 둡니다. 설정에 직접 적은 문구는 원래부터 언어와 무관합니다.
- **가수 대표 표기가 실행 사이에 바뀌어 폴더가 옮겨지던 문제.** 같은 가수의 표기가 둘 이상일 때(`Artist A`/`ARTIST A`, `岡田 有希子`/`岡田有希子`, `Minako Yoshida (吉田美奈子)`/`吉田美奈子`) 중복이 정리되고 나면 파일 수가 달라져 대표 이름이 바뀌었습니다. 이제 디스크에 쓰인 표기(폴더 이름, `가수 - 제목` 파일 이름의 앞부분)를 먼저 따르고, 둘 다 있으면 설정한 표기 선호(라틴/원어)를 따릅니다.
- **복사 모드로 같은 정리를 다시 실행하면 이미 복사한 곡이 ` (2)`로 또 복사되던 문제.** 대상에 같은 내용의 사본이 있으면 "변경 없음"입니다.
- **폴더 연결(junction·심볼릭 링크)이 위쪽 폴더를 가리키면 같은 곡을 수십 번 읽던 문제.** 연결 폴더는 들어가지 않습니다(실제 폴더를 직접 고르세요).
- **여러 장 앨범에서 다른 디스크의 곡이 중복으로 빠지고 나면 `1-01 …` 이름에서 디스크 번호가 사라져 이름이 바뀌던 문제.** 이미 디스크 번호가 쓰인 이름은 유지합니다. 처음 정리하는 한 장짜리 앨범은 전과 같이 디스크 번호를 뺍니다.

### 확인한 것

- 무작위 시나리오 2,400개(정리 위치 4곳 × 무작위 옵션·언어·태그가 섞인 앨범·다중 디스크·베스트 앨범 중복·cue와 부속 파일·가수 표기 변형·이상한 문자·읽기 전용·정크 파일): 어떤 파일도 사라지지 않음, 새 경로가 겹치지 않음, 다시 실행하면 할 일 0, 언어를 바꿔도 할 일 0, 되돌리면 처음과 똑같음 — 모두 통과. 결함마다 전용 시험을 두었고, 규칙을 하나씩 깨뜨려 보는 시험 14개가 모두 잡혔습니다. 전체 시험 305개(파이썬 3.12·3.14), 화면 시험 3회 연속 통과.
- **실제 음악 폴더의 사본**(곡 299개)으로 기본 패턴과 `{year}/{artist} - {title}` 두 가지를 정리 → 다시 실행(할 일 0) → 언어를 바꿔 다시 실행(할 일 0) → 되돌리기: 파일 해시가 처음과 똑같고 원본 폴더는 그대로였습니다.
v0.4.0으로 이미 정리한 폴더는 그대로 쓸 수 있습니다. 되돌리기 기록의 형식은 바뀌지 않았습니다.

**Music Folder Organizer v0.4.1** — fixes found by running 2,400 randomly generated messy music folders through "run, run again, undo". Screens and features are the same as v0.4.0; nothing changes for one ordinary run. Fixed: planning froze when several songs with very long titles landed in one album (the " (2)" number was cut off by the path-length limit); files with no title tag grew a prefix on every run (they now keep their file name and only the folder follows the pattern); cue albums whose sheet cannot follow are renamed once instead of on the second run; switching the language no longer moves "Unknown Album"-style folders; the artist spelling already on the disk (folder or "Artist - Title" file name, alias forms included) is kept when duplicates leave; running the same copy twice no longer adds " (2)" copies; folder junctions and symlinks are not followed; and the disc number already written into names stays when the other disc's duplicates go. Checked on a copy of a real library (299 songs): run, run again (nothing to do), switch language and run again (nothing to do), undo — identical files; the original folder was untouched.
