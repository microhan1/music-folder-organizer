## 음악 폴더 정리 v0.5.0

여러 장짜리 앨범(박스 세트)을 한 폴더로 모으고, 폴더 이름에 연도를 넣는 규칙을 추가한 버전입니다.

### 바뀐 것

- **앨범 이름 끝의 디스크 표시를 디스크 번호로 씁니다.** 앨범 이름이 `贈りもの III [Disc 1]`, `... [Disc 2]`처럼 디스크마다 달라서 박스 세트가 폴더 5개로 갈라지던 것을, `[Disc 1]`·`(Disc 2)`·`[CD 2]`·`- Disc 3`·`CD4` 같은 표시를 떼고 그 숫자를 디스크 번호로 써서 한 앨범 폴더(`贈りもの III/1-01 - …`)로 모읍니다.
  - **정리 규칙에 `{disc}`가 있을 때만** 적용합니다. 기본 규칙은 그대로라, 이미 정리한 폴더가 다시 옮겨지지 않습니다.
  - 파일의 태그는 고치지 않습니다. 표시의 숫자가 디스크 태그와 다르면 앨범 이름을 그대로 둡니다.
  - 기본 규칙에서 여러 장짜리 앨범이 있으면 요약 줄에 "여러 장 앨범 N개 · 디스크 번호 규칙으로" 버튼이 나타나, 누르면 디스크 번호가 들어가는 규칙으로 바꿉니다.
  - 실제 폴더로 시험하니 앨범 폴더 26개가 22개로 줄고(박스 세트 5개 → 1개), 실행 후 되돌리기에서 모든 파일이 원래대로 돌아왔습니다.
- **연도가 들어간 정리 규칙을 추가했습니다.** `{album_artist|artist}/[{year}] {album}/{disc}-{track:02} - {title}` — 폴더 이름이 `[1984] 앨범`이 됩니다. 연도가 없으면 `[연도 미상]`이 되고, 한 장짜리 앨범은 `01 - 제목`처럼 디스크 번호가 빠집니다.
- **곡이 많은 폴더에서 태그를 여러 스레드로 읽습니다**(64곡 이상). 효과는 작고 들쭉날쭉합니다: 1만 곡을 이미 읽은 상태에서는 6.3~6.6초가 5.0~6.0초 정도로 줄고, 처음 읽을 때는 순서대로 읽다가 14초 넘게 멈칫하던 경우가 스레드에서는 나타나지 않았습니다(표본이 작아 배율은 말하기 어렵습니다).
- **영어·일본어·중국어 화면에서 새 버전 알림의 [업데이트]는 영어 판 툴 페이지를 엽니다**(서버가 영어 주소를 줄 때만). 한국어 화면은 그대로입니다.

저장 형식은 그대로라 이전 버전으로 정리한 것도 되돌릴 수 있습니다.

**Music Folder Organizer v0.5.0** — gathers box sets into one album folder and adds a year-in-folder pattern. A disc mark at the end of an album name (`Box [Disc 2]`, `(CD2)`, `- Disc 3`) is now taken as the disc number, **only when the folder pattern uses `{disc}`**; the default pattern is unchanged, so folders from earlier runs are not moved again, and file tags are never written (a mark that disagrees with the disc tag is left alone). With the default pattern, a button offers the disc pattern when multi-disc albums are found. On a real library the album folders dropped from 26 to 22 (a five-disc box set became one folder) and Undo restored every file. New preset: `{album_artist|artist}/[{year}] {album}/{disc}-{track:02} - {title}` (`[1984] Album`). Folders of 64+ songs are read by several threads (a small, uneven gain). On English, Japanese and Chinese screens the update notice's **Update** opens the English tools page when the server provides one. The undo log format is unchanged.
