## 음악 폴더 정리 v0.2.0

실제 음악 폴더로 써 보며 드러난 세 가지를 고쳤습니다.

### 바뀐 것

- **앨범 부속 파일도 함께 옮깁니다.** 한 폴더의 곡이 모두 같은 새 폴더로 갈 때, 그 앨범의 `.cue`·`.log`·`.txt`·`.nfo`·`.m3u`·`.pdf`·이미지와 그런 파일만 든 하위 폴더(`Artwork`·`Scans` 등)도 따라갑니다.
  - 곡이 여러 앨범으로 흩어지는 폴더, 목록에 없는 파일(개인 문서 등), 대상에 같은 이름이 있는 파일은 그 자리에 둡니다. 곡 하나라도 옮기다 실패하면 그 앨범의 부속 파일은 옮기지 않습니다.
  - **cue가 있는 앨범**은 곡 파일명을 바꾸지 않고 폴더만 정리합니다(cue가 깨지지 않게). 일본어 Shift-JIS cue도 읽습니다.
  - 옵션 "앨범 부속 파일도 함께"(기본 켬), 명령줄 `--no-sidecars`.
  - 실제 폴더에서 정리 후에도 남던 원래 앨범 폴더가 27개 중 16개 → 1개로 줄었습니다.
- **베스트 앨범 곡을 중복으로 치우지 않습니다.** 원래 앨범과 베스트 앨범에 실린 같은 곡은 한 그룹으로 보여 주되 **앨범마다 하나씩 남기고**, 같은 앨범 안의 여분(예: 같은 앨범의 mp3와 flac)만 정리합니다. 중복 탭 그룹 이름에 "앨범 n개"가 표시됩니다.
  - 명령줄 `--dedupe`도 같은 규칙입니다. 실제 폴더에서 옮기는 곡이 77곡 → 9곡(같은 앨범을 두 번 받은 폴더)으로 줄었습니다. 다른 앨범끼리도 하나만 남기려면 `--dedupe-across-albums`.
- **음악 정보 채우기로 바로 엽니다.** 태그 부족 파일이 있으면 요약 줄 오른쪽에 **음악 정보 채우기로 열기**가 나타납니다. 그 파일들(mp3·flac·m4a·ogg)을 [음악 정보 채우기](https://github.com/microhan1/music-tag-filler)에서 열고, 그 창을 닫으면 태그를 다시 읽습니다. 위치는 자동으로 찾고, 못 찾으면 한 번만 묻습니다.

### 고친 것

- 중복을 정리한 뒤 다시 실행하면 가수 폴더 이름이 바뀌어(`岡田有希子` ↔ `岡田 有希子`) 정리한 파일을 또 옮기던 문제. 이제 이미 폴더가 있는 표기를 먼저 씁니다.
- 긴 원본 경로에서 "폴더 선택…" 버튼이 잘리던 문제, 좁은 창에서 일부 라벨이 잘리던 문제.

저장 형식(`organize_log.json`, `artists.json`, `settings.json`)은 그대로라 이전 버전으로 정리한 것도 되돌릴 수 있습니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.2.0** — Album extras (`.cue`, `.log`, `.txt`, `.nfo`, `.m3u`, `.pdf`, images and folders such as `Artwork/`) now follow an album when all its songs go to one new folder; albums with a cue sheet keep their file names. A song on several albums (an original and a best-of) keeps one file per album, and only extra copies within an album go to `_Duplicates` (`--dedupe-across-albums` for the old behaviour). Files with missing tags can be opened straight in Music Tag Filler, and the tags are read again when it closes. Also fixed: a rerun after removing duplicates could rename an artist folder. File formats are unchanged; earlier runs can still be undone.
