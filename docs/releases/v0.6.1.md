## 음악 폴더 정리 v0.6.1

설정 창의 체크 상자만 바뀐 버전입니다. 정리·중복 찾기·이름으로 추정·되돌리기는 v0.6.0과 같습니다.

### 바뀐 것

- **설정 창 「새 버전 확인」 상자가 켜지면 ✓로 보입니다.** 지금까지는 켜진 상자에 초록 X가 그려져 꺼진 것처럼 읽히기도 했습니다. 이제 켜면 초록 상자에 흰 ✓, 끄면 흰 상자입니다. 짝 도구 「음악 정보 채우기」와 같은 모양입니다.
- **화면 배율에 맞춰 상자가 커집니다.** 100%에서는 예전과 같은 크기(11px)이고, 125%에서 13px, 150%에서 16px입니다. 예전에는 배율과 상관없이 11px이라 150%에서 글자보다 작았습니다. 설정 창 크기와 줄 간격은 그대로입니다.
- 프로그램이 인터넷에 나가는 것은 여전히 새 버전 확인(하루 한 번, 설정에서 끌 수 있음)뿐입니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.6.1** — Only the check box in the Settings window changed; organizing, duplicates, name-based guesses and undo are as in v0.6.0. The "Check for updates" box now shows a white tick on a green box when it is on (it used to draw a green X), and a plain white box when it is off, the same as in the sister tool Music Tag Filler. The box also grows with the display scale: 11 px at 100 % as before, 13 px at 125 %, 16 px at 150 % (it used to stay at 11 px and looked smaller than the text). The window size and line spacing are unchanged. The only network access is still the once-a-day update check, which you can turn off in Settings.
