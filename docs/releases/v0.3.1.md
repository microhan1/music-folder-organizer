## 음악 폴더 정리 v0.3.1

되돌리기 기록을 더 안전하게 다루도록 고친 버전입니다. 화면과 기능은 v0.3.0과 같습니다.

### 고친 것

- **실행 중간에 되돌리기 기록 저장이 실패하면 멈춥니다.** 지금까지는 첫 저장만 확인하고, 50개마다 하는 중간 저장이 실패하면(로그 파일을 다른 프로그램이 잠갔거나 디스크가 꽉 찬 경우) 그대로 계속 옮겼습니다. 그러면 기록되지 않은 파일은 되돌리기로 돌아오지 않았습니다.
  - 이제는 저장이 실패한 자리에서 멈추고, 그때까지 옮긴 것을 한 번 더 저장합니다. 결과 창에 "되돌리기 기록을 저장하지 못해 중간에 멈춤"이 나오고, 마지막 저장마저 실패하면 되돌리기에서 빠질 수 있는 파일이 있다고 알려 줍니다.
- **되돌리기도 시작 전에 기록을 쓸 수 있는지 확인합니다.** 쓸 수 없으면 아무 파일도 되돌리지 않고 알려 줍니다. 파일을 되돌린 뒤 "되돌림" 표시만 저장하지 못한 경우도 이제 경고로 보입니다(전에는 조용히 넘어가 기록에 아직 안 되돌린 실행으로 남았음).
- 기록 저장이 실패했을 때 `organize_log.json.part` 파일이 남던 문제.

평소처럼 저장이 잘 되는 환경에서는 달라지는 것이 없습니다. 저장 형식도 그대로라 이전 버전으로 정리한 것도 되돌릴 수 있습니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.3.1** — safer undo log handling; screens and features are the same as v0.3.0. If the undo log cannot be saved part way through a run (log locked by another program, disk full), the run now stops there instead of moving on unrecorded, saves what it has once more and says so in the result. Undo checks that the log is writable before putting anything back, and reports when it could not record the undo. A failed save no longer leaves `organize_log.json.part` behind. Nothing changes when saving works; the log format is unchanged.
