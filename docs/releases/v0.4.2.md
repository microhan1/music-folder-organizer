## 음악 폴더 정리 v0.4.2

새 버전이 나왔는지 알려 주는 기능을 넣은 버전입니다. 정리·중복 찾기·되돌리기는 v0.4.1과 같습니다.

### 바뀐 것

- **새 버전 확인.** 프로그램을 켜면 하루 한 번, 새 버전이 있는지 책갈피 서버(chaekgalpi.co.kr)에 물어봅니다. 보내는 것은 **도구 이름과 버전뿐**이고 파일·폴더 경로는 보내지 않습니다.
  - 새 버전이 있으면 창 아래에 한 줄로 알려 줍니다: "새 버전 0.4.3이 있습니다 (현재 0.4.2) · **업데이트** · **다음에**". **업데이트**는 책갈피 툴 페이지를 열고, **다음에**를 누르면 그 버전은 다시 알리지 않습니다.
  - 새 버전을 자동으로 내려받거나 바꾸지 않습니다. 인터넷이 안 되면 아무 말도 하지 않습니다.
  - **설정**에서 "새 버전 확인"을 끄면 묻지 않습니다(기본은 켬).
- 이에 따라 "인터넷 연결 없이 동작합니다"라는 안내를 "(새 버전 확인만 예외 — 도구 이름·버전만, 하루 한 번, 설정에서 끔)"으로 고쳤습니다. 그 밖의 기능은 지금처럼 인터넷 없이 동작합니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.4.2** — adds an update check. Once a day at start the tool asks the 책갈피 server (chaekgalpi.co.kr) whether a newer version exists, sending only its name and version — no files or paths. A newer version is announced in one line at the bottom of the window (**Update** opens the 책갈피 tools page, **Later** stops showing that version); nothing is downloaded or replaced automatically, and without a connection it says nothing. It can be turned off in Settings ("Check for updates", on by default). Everything else still works without an internet connection; organizing, duplicates and undo are unchanged from v0.4.1.
