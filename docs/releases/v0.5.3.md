## 음악 폴더 정리 v0.5.3

exe를 켜면 **시작 그림**이 먼저 뜨는 버전입니다. 정리·중복 찾기·되돌리기·의견 보내기는 v0.5.2와 같습니다.

### 바뀐 것

- **시작 그림**: 더블클릭하고 0.5초쯤 뒤에 아이콘과 툴 이름(한국어·영어·중국어·일본어)이 든 작은 그림이 뜹니다. 한 파일 exe는 켤 때마다 압축을 푸는 데 몇 초가 걸리는데, 그동안 아무것도 안 보여서 두 번 누르게 되던 것을 막습니다. 창이 다 그려지면 그림은 바로 사라지고 작업 표시줄에는 창 하나만 남습니다.
- 그림이 뜨는 시간과 창이 뜨는 시간(같은 PC에서 두 번째 실행부터): 그림 0.5초, 창 4.6~5.7초. 창이 뜨는 시간은 v0.5.2와 같습니다.
- 처음 받은 exe의 첫 실행은 Windows 보안(백신)이 파일을 먼저 훑어서 그림이 뜨기까지 10초 넘게 걸릴 수 있습니다. 두 번째부터는 위 시간입니다.
- 프로그램이 하는 일은 바뀌지 않았습니다. 인터넷에는 여전히 새 버전 확인(하루 한 번, 설정에서 끌 수 있음)만 나갑니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

SHA-256: `(빌드 뒤 기입)` (music-folder-organizer.exe (빌드 뒤 기입)바이트, 2026-11-17 빌드)

**Music Folder Organizer v0.5.3** — The exe now shows a small **start-up picture** (the icon and the tool's name in Korean, English, Chinese and Japanese) about half a second after you double-click it, so the few seconds a single-file exe spends unpacking no longer look like nothing happened. The picture goes away as soon as the window is drawn, and only one item stays on the taskbar. The window itself appears in the same time as v0.5.2 (4.6–5.7 s from the second launch on the same PC; the very first launch of a freshly downloaded exe can take over 10 s while Windows security scans the file). Organizing, duplicates, undo and feedback are unchanged. The only network access is still the once-a-day update check, which you can turn off in Settings.
