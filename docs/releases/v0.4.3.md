## 음악 폴더 정리 v0.4.3

v0.4.2에 넣은 "새 버전 확인"을 고친 버전입니다. 정리·중복 찾기·되돌리기는 그대로입니다.

### 고친 것

- **새 버전을 확인하는 동안 창을 닫으면 프로그램이 비정상 종료될 수 있던 문제.** 프로그램을 켠 직후(1.5초 뒤부터 몇 초 동안) 서버의 답을 기다리는 사이에 창을 닫으면, 드물게 "Tcl_AsyncDelete" 오류로 프로그램이 죽을 수 있었습니다(같은 구조의 다른 책갈피 툴에서 확인됨). 이제 확인 작업이 창을 붙잡지 않으므로 언제 닫아도 안전합니다.
- 알림 문구를 "새 버전이 나왔습니다: 0.4.4 (현재 0.4.3)" 형태로 바꿨습니다.

새 버전 확인의 동작(하루 한 번, 도구 이름·버전만 보냄, 설정에서 끔, 자동으로 내려받지 않음)은 v0.4.2와 같습니다.

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.4.3** — fixes the update check added in v0.4.2: closing the window while it was still waiting for the server (a few seconds after start) could, rarely, end the program with a "Tcl_AsyncDelete" error (seen in another 책갈피 tool with the same code). The check no longer holds on to the window, so closing is safe at any time. The Korean notice now reads "새 버전이 나왔습니다: {latest} (현재 {current})". Everything else is unchanged.
