## 음악 폴더 정리 v0.6.0

음악이 아니라서 지금까지 보이지 않던 큰 파일(SACD 이미지 `.iso`, 압축 `.zip` 등)을 다루는 버전입니다. 곡 정리·소리 비교·되돌리기는 v0.5.3과 같습니다.

### 바뀐 것

- **정리하지 않는 큰 파일을 알려 줍니다.** 음악도 앨범 부속 파일도 아닌 8MB 이상 파일이 있으면 요약 줄에 "음악이 아니라 정리하지 않는 큰 파일 N개(크기)"가 나옵니다. 명령줄 `--dry-run`은 목록도 보여 줍니다. `.iso`만 든 폴더처럼 음악이 하나도 없어도 알려 줍니다. 이 파일들은 예전처럼 옮기지 않습니다.
- **바이트까지 똑같은 앨범 이미지·압축 파일을 중복으로 묶습니다.** `.iso .img .bin .mdf .nrg .zip .rar .7z .tar .tgz` 중 8MB 이상이 대상입니다. 크기가 같은 것끼리만 내용을 비교하고, 하나만 남기고 나머지는 `_중복` 폴더로 옮깁니다. 폴더 안의 표지·`.cue`·`Artwork`도 함께 갑니다. 크기만 같고 내용이 다르면 그대로 둡니다. 중복 탭의 비트레이트 칸에는 크기가 나오고, 되돌리기도 곡과 같게 됩니다.
- **파일 이름으로 가수·앨범 폴더를 제안합니다("추정").** 이미지·압축 파일의 이름이 `가수 - 앨범 (연도) [형식]` 꼴이면 `가수/앨범/` 아래로 옮길 것을 표에 제안합니다. 처음에는 체크가 꺼져 있고, 체크한 것만 옮깁니다. 폴더 안의 표지와 `Artwork`가 함께 갑니다. 공동 이름(`A & B`)은 따로 가수 폴더가 됩니다. 이름이 읽히지 않는 파일은 그대로 둡니다. 명령줄은 `--from-names`를 줘야 옮깁니다. 파일 이름만 읽고 폴더 이름은 읽지 않아서, 한 번 정리한 파일이 다음 실행에서 다시 옮겨지지 않습니다.
- 프로그램이 인터넷에 나가는 것은 여전히 새 버전 확인(하루 한 번, 설정에서 끌 수 있음)뿐입니다.

**Music Folder Organizer v0.6.0** — This version deals with the big files that used to be invisible because they are not music (SACD images, `.zip` archives). Song organizing, sound matching and undo are as in v0.5.3. (1) The summary line now tells how many big non-music files (8 MB and up) are left alone, with their size; `--dry-run` lists them, also for a folder that holds no music at all. (2) Disc images and archives (`.iso .img .bin .mdf .nrg .zip .rar .7z .tar .tgz`) that are byte-for-byte identical are grouped as duplicates: one stays, the others go to the duplicates folder together with their covers, `.cue` and `Artwork`, and undo works as for songs. Same size with different content is left alone. (3) When such a file is named `Artist - Album (year) [format]`, the tool proposes filing it under `Artist/Album/` as a guess: unticked at first, only the ticked ones move, with the covers and `Artwork` in the folder. A joint credit (`A & B`) gets its own artist folder. On the command line, pass `--from-names` to move them. Only the file name is read, never the folder name, so a file that was filed once is not moved again on the next run. The only network access is still the once-a-day update check, which you can turn off in Settings.
