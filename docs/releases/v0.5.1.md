## 음악 폴더 정리 v0.5.1

창 위쪽에 **의견 보내기**를 더한 버전입니다. 정리·중복 찾기·되돌리기는 v0.5.0과 같습니다.

### 새로 생긴 것

- **의견 보내기**: 머리줄의 「설정」 왼쪽에 있습니다. 누르면 브라우저에서 책갈피 툴 페이지의 의견 칸(https://chaekgalpi.co.kr/tools/musicfolder#feedback)이 열리고, 로그인 없이 안 되는 것·불편한 것·바라는 기능을 보낼 수 있습니다. 한국어가 아닌 화면에서는 영어 페이지가 열립니다.
  - 프로그램은 브라우저를 열기만 하고 아무것도 보내지 않습니다. 주소에는 이 프로그램에서 왔다는 표시와 버전만 붙습니다.
  - 브라우저가 열리지 않으면 주소를 보여 주니 복사해서 브라우저에 붙여 넣으면 됩니다(알림 창에서 Ctrl+C).
- GitHub Issues도 그대로 받습니다.

![머리줄: 의견 보내기 · 설정 · 언어](https://raw.githubusercontent.com/microhan1/music-folder-organizer/main/docs/feedback_button.png)

### 다운로드

`music-folder-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없고, 소리 비교용 fpcalc(Chromaprint, LGPL-2.1)가 들어 있습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Music Folder Organizer v0.5.1** — adds **Send feedback** to the header (left of Settings). It opens the feedback box on the 책갈피 tools page in your browser (the English page on a non-Korean screen), where you can write without signing in; the app itself sends nothing. If no browser opens, the address is shown so you can copy it. GitHub Issues are still welcome. Organizing, duplicates and undo are unchanged from v0.5.0.
